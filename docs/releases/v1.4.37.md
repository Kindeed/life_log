# LifeLog v1.4.37

版本：`1.4.37+43`。

结合项目详情截图重新整理信息结构，并修复账目、记录归属和刷新逻辑。

- 紧凑的“动态／照片／账目”统一页签、卡片与主操作；筛选收进一个菜单，添加照片、支出与凭证集中到一个添加入口。
- 动态按日期分组，照片显示缩略图，出差记录可直接编辑；浅深色和大字体下内容按空间重排。
- 支出与凭证分别展示，支出按原币种汇总；不再用无关联凭证扣减支出，也不为普通支出推测报销状态。
- 明确关联优先于名称，修复改名与同名项目混入记录；费用与出差跟随本地变化更新，旧读取不能覆盖新数据。
- 进入详情复用父页面四个数据源，长列表只构建可见卡片，减少重复读取和监听。
- 批量照片操作有进度及结果反馈，失败保留选择并允许重试；修改节点、归档与取消归档保留项目封面。
- 保留此前订阅跨月提醒、日历信息、保存反馈及同步数据保护。

885 项回归测试通过，新增 34 项；严格静态分析、455 个 Dart 文件格式、锁定依赖及原生数据库检查通过。真实 Flutter 页面覆盖浅深色、390px 普通字体及 320px 两倍字体；没有 Android 实机帧率基准。

无数据库模型、运行依赖或云端迁移变化。照片继续只保存在本地。

安装包由 GitHub Actions 正式签名构建，通常选择 `LifeLog-v1.4.37-arm64-v8a-release.apk` 覆盖安装。

优化依据与验收边界见 [项目详情整体审查](https://github.com/Kindeed/life_log/blob/v1.4.37/docs/reviews/2026-10-07-project-detail-review.md)。
