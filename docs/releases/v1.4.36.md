# LifeLog v1.4.36

版本：`1.4.36+42`。

继续减少保存等待和滚动开销。核对 Telegram 的公开客户端及 TDLib / Bot API / MTProxy 后，将适合 LifeLog 的本地响应、合并调度、媒体尺寸控制和稳定列表状态落实到实际页面。

- 项目、费用、凭证保存及关联项目创建不再等待整轮云同步，本地写入完成即可结束；后台失败仍保留待同步记录。
- 一次订阅排序只触发一次后台同步请求。
- 今日工时及订阅合并连续刷新，避免旧请求覆盖最新记录。
- 相册缩略图按格子实际尺寸解码，减少内存开销；原图、全屏预览及照片本地边界保留。
- 同步状态页支持惰性任务列表、刷新保留滚动位置、失败保留记录及重试；正在处理的冲突滚走返回也不会重复提交。
- 任务标题更易读，编号与诊断内容在详情查看；按压动画在滚动时及时释放。
- 保留之前订阅跨月、日历信息、紧凑日期和保存反馈等修复。

851 项回归测试通过，新增 33 项；严格分析、格式、原生数据库及中文截图检查通过。

无数据库模型/schema、云端迁移或运行依赖变化。没有实机帧率基准，也没有新增关闭 App 后持续同步的系统后台服务。

安装包由 GitHub Actions 正式签名构建，通常选择 `LifeLog-v1.4.36-arm64-v8a-release.apk` 覆盖安装。

源码参考与验收依据见 [Telegram 源码优化审查](https://github.com/Kindeed/life_log/blob/v1.4.36/docs/reviews/2026-10-07-telegram-source-optimization.md)。
