# LifeLog v1.4.38

版本：`1.4.38+44`。

项目节点改为按顺序保留的阶段，每个阶段可以查看和添加自己的记录；金额录入同时优化。

- 阶段管理支持追加、上移／下移，保存时保留旧阶段、项目状态与封面。
- 一个阶段选择入口统一筛选动态、照片和账目，展示阶段记录数量和各原币种支出；历史阶段与未分阶段记录仍可回看。
- 新照片、支出与凭证预选所查看的阶段，修复保存前阶段被清空的问题，以及凭证换项目仍携带旧项目关联的问题。
- 旧照片可批量设置阶段，操作有进度、结果和失败重试；本地事务失败不会留下部分修改。
- 支出与凭证共用金额／币种输入，拒绝非有限值、负数和超出币种精度的新金额；已有历史金额保留原值，不隐式舍入。
- 分类、字段和卡片统一圆角与边缘，大字体下分类改用选择器；保存和删除期间防止重复操作，保存反馈不再等待刷新回调。

照片只新增可空的本地阶段字段，Isar 自动升级已有数据库；没有照片云同步、云端迁移或运行依赖变更。未分阶段的旧照片不会被按日期自动分配，可以手动整理。阶段采用手动选择，可回看和补记。

924 项回归测试通过，新增 39 项；严格分析、465 个 Dart 文件格式、原生数据库和浅深色／大字体页面检查通过。真实 v1.4.37 照片数据库升级及原图完整性测试通过。

安装包由 GitHub Actions 正式签名构建，通常选择 `LifeLog-v1.4.38-arm64-v8a-release.apk` 覆盖安装。

参考项目与验收说明见 [项目阶段与金额录入审查](https://github.com/Kindeed/life_log/blob/v1.4.38/docs/reviews/2026-10-07-project-stages-and-money.md)。
