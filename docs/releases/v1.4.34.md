# LifeLog v1.4.34

版本：`1.4.34+40`。

修复工时日历日期格过长、保存缺少反馈，以及订阅修改保存等待云同步的问题。

- 日期格使用更小的圆角和更紧凑的高度；农历、节日、假期、工时与同日多条记录仍可查看。大字体保持可用。
- 工时、订阅保存有进度与成功提示；错误直接显示在编辑页或弹窗中，便于重试。
- 订阅在本地写入成功后返回，云同步在后台继续。网络失败时保留待同步状态。
- 工时保存后及时退出编辑，由数据库变更刷新页面；避免重复读取、重复提交和保存删除重叠。
- 保留 v1.4.33 的订阅跨月提醒修复，无数据库或云端迁移。

安装包由 GitHub Actions 正式签名构建。通常选择 `LifeLog-v1.4.34-arm64-v8a-release.apk`，直接覆盖安装以保留数据。

验证详情见 [日历与保存回归记录](https://github.com/Kindeed/life_log/blob/v1.4.34/docs/reviews/2026-10-06-calendar-save-responsiveness.md)。本次没有 Android 实机耗时测量或安装验证。
