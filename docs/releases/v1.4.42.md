# LifeLog v1.4.42

版本：`1.4.42+48`。

项目历史记录的展开目录现在更有层次，月份、日期和当天记录的归属一眼可见。

- 同一月份共享连续背景，日期和记录逐级缩进，细连接线标明所属层级；不同月份之间保留间距。
- 月份标题更突出，展开箭头统一放在标题左侧；日期与星期完整显示，大字体和窄屏下记录数量自然换行。
- 修复深色大字体下分组背景的细横缝，统一展开与收起时的圆角边界。
- 保留阶段／记录类型组合筛选、月份／日期独立折叠、折叠记忆、各范围滚动位置及记录懒加载。

本次仅优化项目展示，不新增数据库结构或云端迁移，依赖保持不变。照片与文字记录继续在本机保存。

75 项项目相关定向测试通过，浅色／深色、390dp 与 320dp／2x 的 12 张目录状态预览已检查。正式签名 APK 由 GitHub Actions 完成发布验证并构建。验证范围与已有功能限制见 [项目评审](https://github.com/Kindeed/life_log/blob/v1.4.42/docs/reviews/2026-10-11-project-channel-workflow.md)。

通常选择 `LifeLog-v1.4.42-arm64-v8a-release.apk`，使用正式签名包覆盖安装，保留现有应用数据。
