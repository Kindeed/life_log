# LifeLog v1.4.32

版本：`1.4.32+38`。

工时、项目、更多采用统一的柔和配色、圆角层次和顶部操作区。切页、按钮按压与底部导航加入连续动效，并尊重系统的减少动态效果设置。

- 日历同时显示农历、节气/节日、班休、工作状态和多条记录；首次打开也会及时显示异步加载的日期信息。
- 保留同日多条记录，主操作继续编辑当天最新的普通工时；修复大字体与短日历单元格溢出。
- 项目创建支持未保存提醒、忙碌状态保护，迟到的成功响应不会关闭父页面。
- 同步绑定账号、会话与数据库生命周期；迟到的响应保留新编辑和删除，重试使用持久化的稳定身份。
- 冲突选择实际应用本地、远端或复制结果；复制建立独立身份及凭证文件，处理前等待已发出的同步请求完成。
- 修复附件中断重试、迟到上传回写及旧附件覆盖选定文件；上传路径变更会继续同步到凭证记录。
- 恢复备份会重新连接既有数据库服务与订阅，强制后续云端全量拉取；拒绝损坏候选，恢复和回滚均失败时保留可恢复的原始快照。
- Linux CI 必须执行真实 Isar 测试，缺少兼容原生库会直接失败。

项目照片继续仅保存在本地。此次版本包含新增的本地冲突账号字段，云端协议仍为 2，无需新增云端迁移。

安装包由 GitHub Actions 使用正式签名构建：通常选择 `LifeLog-v1.4.32-arm64-v8a-release.apk`；另提供 armeabi-v7a 和 x86_64 包。升级前建议导出本地备份，直接覆盖安装并保留应用数据。

验证范围与尚未解决的外部配置见 [本轮复审记录](https://github.com/Kindeed/life_log/blob/v1.4.32/docs/reviews/2026-10-02-release-regression.md)。本地验证不包含 Android 实机安装或生产 Supabase 端到端检查；U308（Auth 泄露密码保护设置）仍待具有项目权限的环境核实。
