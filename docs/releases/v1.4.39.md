# LifeLog v1.4.39

版本：`1.4.39+45`。

统一保存反馈、状态、暗色主题和动效，整理“更多”入口，并修复历史记录与多币种展示。

- 保存成功使用紧凑提示；凭证错误和识别结果留在当前弹层，长文字及大字体可换行。
- 状态标签共用配色与尺寸规则，改善暗色对比度；订阅状态与下次扣费分开显示。
- “更多”按账户、记录与分析、应用设置、专业工具组织；设置行统一，诊断集中到“关于与诊断”。数据备份明确只包含数据库，不包含照片及凭证文件。
- 页面和弹层统一运动规则，底部导航跟随滑动；工时类型切换保留输入草稿和焦点，兼容减少动画与平台返回。
- 全部记录可查询历史工时，统一日期筛选，分类内可新增和编辑，读取失败可重试；列表按需构建，每次展示 40 条。
- 支出和凭证保留原币种与历史金额精度，汇总按币种分开；人民币估算单独标识。修复订阅非有限金额和 OCR 金额固定两位小数的问题。
- 统计与时间线切换账户时清空旧缓存，旧请求不会覆盖新账户；修正窄屏与大字体的栏目标题对齐。
- 适配新 SDK 的拖动排序、列表缓存与展开动画，修复拖动时按压控件的生命周期问题，以及弹层背景遮住列表点击反馈的问题。

保留 Flutter 和现有本地优先架构。取消 Flutter 3.38.5 精确版本要求，CI 跟随 stable 通道，锁文件更新 SDK 必需的依赖，CI 仍按锁文件获取。本版没有数据库 schema、云同步协议或签名配置变更，照片继续只在本地保存。

Flutter 3.47.7 / Dart 3.13.5 上本地 1005 项测试通过，新增 81 项；严格静态分析、481 个 Dart 文件格式、锁文件校验、原生 Isar、代码生成和浅深色／大字体布局检查通过。Android 安装包通过 GitHub Actions 的 stable SDK 验证并正式签名构建。

数据库范围分页与真机帧率仍待优化和测量。既存 OCR 并发与识别币种应用策略继续跟踪，详见 [本轮评审](https://github.com/Kindeed/life_log/blob/v1.4.39/docs/reviews/2026-10-11-ui-and-architecture-review.md)。

通常选择 `LifeLog-v1.4.39-arm64-v8a-release.apk`。升级前导出备份，使用正式签名包覆盖安装，保留现有应用数据。
