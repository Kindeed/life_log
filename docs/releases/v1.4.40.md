# LifeLog v1.4.40

版本：`1.4.40+46`。

项目记录改为频道式阅读，按阶段组织内容，并支持按月份、日期折叠历史记录。

- 一个频道集中展示文字、照片及其说明、出差、费用和凭证；照片浏览与账目管理可按需打开。
- 阶段和记录类型可以组合筛选。点击月份收起整月，点击日期展开当天；默认展开最新一天，也可全部展开或收起。
- 刷新和切换筛选保留折叠选择；各阶段／类型分别记住滚动位置，工具返回恢复原位置。
- 可独立添加文字记录，记录设备状态、生产安排、客户沟通和问题跟进，编辑内容、日期及阶段；新记录继承当前项目和阶段。
- 照片备注和出差说明更易阅读，浅色、深色及大字体布局统一；日期控件支持辅助功能及减少动画设置。
- 修复同名项目的照片归属、恢复失败处理和账户切换旧缓存／滚动位置残留。云端删除项目时保留本机文字所在的项目档案，仍可查看和补记本机文字、照片。

本版新增本地文字记录集合和项目归档标记，已用真实 v1.4.39 数据库验证升级及备份恢复。照片与文字记录只在本机保存；数据库备份包含文字，仍不包含照片和凭证文件。本版不需要 Supabase 迁移，同步协议保持不变。

项目及直接受影响路径的定向测试、严格静态分析和浅色／深色、大字体布局检查通过；发布由 GitHub Actions 完成验证及正式签名构建。完整验证记录及已知限制见 [本轮评审](https://github.com/Kindeed/life_log/blob/v1.4.40/docs/reviews/2026-10-11-project-channel-workflow.md)。

通常选择 `LifeLog-v1.4.40-arm64-v8a-release.apk`。升级前导出备份，使用正式签名包覆盖安装，保留现有应用数据。
