# LifeLog v1.4.35

版本：`1.4.35+41`。

优化同步时反复刷新页面、项目封面占用过多解码内存和切栏中途误选等问题，继续完善柔和、清晰的界面。

- 第一条数据变化立即刷新，连续同步变化合并为少量后续读取；已有内容保持可见，旧请求不会覆盖新结果。
- 修复完整同步请求遗漏与异常后后续请求遗漏；重试队列使用现有索引查找，减少无效读取。
- 项目缩略图按显示宽度解码，搜索和排序复用已有照片分组。
- 订阅刷新保留当天有效汇率；失败时保留已有记录，并标明使用今日缓存汇率。
- 三栏标题和内容层级更清晰，项目概览收拢为一个面板；汇总区域对齐，快速切栏保持最后选择。
- 保留 v1.4.33/v1.4.34 的订阅跨月、紧凑日历和保存反馈修复。

没有数据库 schema 或云端迁移。照片和原图仍只在本地，缩略图优化不修改文件。

安装包由 GitHub Actions 正式签名构建。通常选择 `LifeLog-v1.4.35-arm64-v8a-release.apk`，直接覆盖安装以保留数据。

设计参考、构造压力场景与历史回归见 [同步及前端效率审查](https://github.com/Kindeed/life_log/blob/v1.4.35/docs/reviews/2026-10-07-sync-frontend-efficiency.md)。本次没有 Android 实机帧率、耗时或内存测量。
